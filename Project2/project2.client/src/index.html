🔍 DevTools Inspector (F12)

Right-click any element → Inspect to see:

  • All applied styles and their source (external, internal, inline)
  • Specificity and which rules are overridden (crossed out)
  • Box model visualization (margin, border, padding, content)
  • Computed final values for all properties
  • Live editing to test changes!
