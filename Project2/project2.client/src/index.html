<style> tag - Styles defined in <head>. Useful for page-specific styles.

style attribute - Highest specificity (1,0,0,0) but NOT recommended - hard to maintain.

JavaScript Fundamentals

1. Variables & Data Types
// Variables: var, let, const
var oldWay = "Don't use var anymore"; // Function-scoped, hoisted
let changeable = "Use let for variables that change"; // Block-scoped
const constant = "Use const for constants"; // Block-scoped, cannot reassign

// Data Types
let stringType = "Hello World";           // String
let numberType = 42;                      // Number
let booleanType = true;                   // Boolean
let arrayType = [1, 2, 3];               // Array
let objectType = { name: "John" };       // Object
let undefinedType;                        // Undefined
let nullType = null;                      // Null
2. Functions
// Function Declaration
function greet(name) {
  return "Hello, " + name;
}

// Arrow Function (ES6)
const greetArrow = (name) => {
  return `Hello, ${name}`;
};

// Shorthand Arrow Function
const greetShort = name => `Hello, ${name}`;

// Function with default parameters
const greetDefault = (name = "Guest") => {
  return `Hello, ${name}`;
};
3. Arrays & Objects
// Arrays
const fruits = ['apple', 'banana', 'orange'];
fruits.push('grape');        // Add to end
fruits.pop();               // Remove from end
fruits.forEach(f => console.log(f));

// Array Methods
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(n => n * 2);
const evens = numbers.filter(n => n % 2 === 0);
const sum = numbers.reduce((a, b) => a + b);

// Objects
const person = {
  name: "John",
  age: 30,
  greet() {
    return `I'm ${this.name}`;
  }
};
📘 How TypeScript Relates to JavaScript
❌ JavaScript (No Type Safety)
// No type checking - errors at runtime!
function add(a, b) {
  return a + b;
}

add(5, 10);        // ✅ 15
add("5", "10");    // ⚠️ "510" (string concat!)
add(5, "10");      // ⚠️ "510" (unexpected!)

let user = { name: "John" };
user.age = 30;     // ✅ Works
user.email();      // 💥 Runtime error!
✅ TypeScript (Type Safety)
// Type checking - errors at compile time!
function add(a: number, b: number): number {
  return a + b;
}

add(5, 10);        // ✅ 15
add("5", "10");    // ❌ Compile error!
add(5, "10");      // ❌ Compile error!

interface User {
  name: string;
  age?: number;    // Optional property
}
let user: User = { name: "John" };
user.age = 30;     // ✅ Works
user.email();      // ❌ Compile error!
🔑 Key Differences:
  • TypeScript is a superset of JavaScript - All valid JS is valid TS
  • TypeScript adds static typing - Catch errors before runtime
  • TypeScript compiles to JavaScript - Browsers only run JS
  • TypeScript adds modern features - Interfaces, generics, decorators, etc.
  • Better IDE support - Autocomplete, refactoring, intellisense
💡 In this Angular project: Your .ts files are TypeScript, which get compiled to JavaScript that runs in the browser. Open any .ts file in your project to see TypeScript in action!
